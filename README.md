## 🚀 О проекте
**Dota 2 CyberHub** — это интерактивная платформа для фанатов киберспорта. Сайт разработан с использованием чистых веб-технологий (HTML5, CSS3, JavaScript) и поддерживает модульную архитектуру с динамическим управлением контентом.

---

## ✨ Основной функционал

*   🏆 **Интерактивная сетка турнира:** Полное расписание Main Event (Верхняя сетка, Нижняя сетка, Полуфиналы, Финалы и Гранд-финал) с актуальными слотами и датами.
*   📰 **Главная / Стрим:** Свежие киберспортивные новости и встроенный плеер для просмотра матчей в реальном времени.
*   📊 **Аналитика матчей:** Подробные разборы встреч и превью противостояний.
*   📈 **Рейтинг EPT:** Актуальное положение профессиональных команд в мировом рейтинге.
*   👥 **Команды:** База участников турниров с логотипами и информацией.
*   ⚔️ **Мета героев:** Фильтруемая база героев патча с актуальными сборками предметов и таймингами.
*   🏛️ **Архив TI:** Исторические данные прошлых турниров The International.

---

## 🛠️ Технологии
*   **Frontend:** HTML5, CSS3 (Grid, Flexbox, Glassmorphism-дизайн).
*   **Scripting:** Vanilla JavaScript (модульная архитектура, динамический рендеринг через `dbData`).
*   **Assets:** Официальные медиа-ресурсы и иконки с Liquipedia и Steam CDN.
